# Simple Voice Tool for Trans 使用说明

一款基于 Web Audio API 的语音测试与追踪应用，为跨性别声音训练（女性化 / 男性化）与日常嗓音健康设计。

**隐私承诺**：所有录音与统计数据仅保存在你自己的设备（浏览器 IndexedDB），不上传任何服务器；训练建议 / 周报选择「大模型判断」时，仅把统计指标与备注（不含音频）发送到你自己填写的接口；AI 助手还会发送对话文本与本次选中的长期记忆，均不含音频与原始曲线。

---

## 首次打开

- 第一次打开会进入引导页：选择训练方向（女性化 / 男性化 / 其他）、年龄段与界面语言，并挑选主题外观——引导页顶部用一条连续的音高曲线显示进度，四步依次点亮；都可以之后在设置中修改；
- 打开应用，允许麦克风权限；
- 到「测试」页，在顶部模式胶囊选择模式；默认的悬浮胶囊用录音圆球，经典底栏用音高卡片右下角的扇形录音键，开始后再点一次结束；
- 录完自动进入「分析」页查看报告（可在 设置 → 录音 中修改）；
- 录音过程中每秒把音频写入本机临时草稿：App 被系统结束、浏览器崩溃或切后台太久后，下次启动会提示恢复上次录音；草稿不会上传，可在 设置 → 录音 手动清理。

## 三种测试模式（测试页顶部模式胶囊切换）

- **朗读**：任意读一段文字。反映日常说话状态：音高、语调起伏、连贯度；
- **长音**：舒服地发一个「a」持续到底，发声后静音约 1 秒自动结束。测量气息与控制力（MPT / 稳定度 / 衰减），也是嗓音健康的净化样本；
- **滑音**：从低到高缓慢滑唱 20 秒。绘制声域图（VRP 热图），看真实音域边界。

## 分析页

- **概览与统计表**：音高（均值 / 中位数 / P10–P90 工作音域 / 标准差）、共振峰（共鸣）、能量、嗓音质量（Jitter / Shimmer / HNR / CPPS，以及 H1–H2 / H2–H4 / H1–A3 / 气声度 / 鼻化）四组；
- **声音性别表达参考**：0–100 参考分，把中位基频与 F2−F1 共鸣合成一个连续值；配男性化 ↔ 女性化双极标尺与参考锚点。它是 VFP 风格的声学近似，不是 inaSpeechSegmenter 的 CNN 输出，也不构成诊断——评分锚点与可自定义的音区色带是两套口径；
- **咝音分析**：保存过音频的记录会自动检出 /s/ /x/ /sh/ 等摩擦音帧，给出频谱重心与 P10–P90，并按训练方向标出参考区间（女性化偏 5–10 kHz、男性化偏 2.5–6.5 kHz，仅供训练参考）；
- **图表**：音高 / 共振峰 / 能量 / 语谱图，共享时间区间（拖动任一图下方的窗口联动缩放，统计随之重算）；
- **回放**：保存过音频的记录可回放，播放头同步到各图表；
- **基线 Δ**：在 设置 → 训练 中钉选基线后，自动显示与基线的差值；
- **训练建议**：规则判断（本地生成）或大模型判断（AI），见下文 AI 功能；
- **共振峰目标区**：设定目标 F1/F2 后，元音散点图叠加目标矩形并统计落点命中率；
- **重新分析**：算法参数更新后，可用当前参数重算历史记录（分析页右上角）；
- **分享 / 导出**：右上角分享卡（多种卡面样式 PNG）、帧级 CSV、交互式 HTML、临床报告、MIDI（F0 曲线量化成音符 + 弯音）、Praat 格式与自定义导出模板。

## AI 助手

- **AI 助手**（经典底栏有独立 **AI** 页签；悬浮胶囊下从 设置 → 大模型 进入，或把导航栏切成 AI 工作台）与 AI 对话式地回顾你的测试历史、追问指标含义；
- 助手能看到你的测试记录摘要（受上下文预算限制，较旧记录可能省略；仅统计指标与备注，不含音频）；
- 回答不使用气泡：正文直接渲染在空白处，支持标题 / 列表 / 表格等基本 Markdown；记录图表独立成卡片；
- 模型还可以输出 `genui` 交互组件（沙箱运行、样式跟随主题、不能访问应用数据），用于滑块、切换、对比面板等原生图表表达不了的交互；
- **长期记忆**（设置 → 大模型 → 记忆）：记住你陈述过的事实 / 偏好 / 要求 / 注意，可手动添加、编辑、置顶，或从最近对话离线提取候选；置顶项每轮注入，其余按当前问题相关度注入；只存本机，使用时随助手请求发送；
- 对话保存在本机，可随时清除；配合 设置 → 大模型 使用。

## 历史页

- **列表**：按备注 / 日期 / 模式搜索；长按进入多选，选两条可「对比」（指标 Δ + 音高曲线叠加 + 元音空间叠加）；删除可撤销，同时会进入回收站；
- **趋势**：用声日记热力图（打卡）、平均基频与音域带趋势图（可按模式过滤，长音与朗读不可比）、**AI 周报**（聚合近 7 天生成总结）；
- **花园**：把每条记录渲染成一朵「声音花」，按月分节排布；花瓣/形态随当次音高、共振峰与能量等统计变化，用来看长期形态迁移，并可做 A→B 时间机器动画对比；
- **回收站**：列表右上角的垃圾桶入口；删除的记录保留 30 天（音频一并保留），可单条 / 批量恢复或永久删除，到期自动清理；
- **快捷键**：桌面端支持键盘快捷导航（设置内可查看快捷键说明）。

## 训练相关（设置 → 训练）

- **训练方向与年龄段**：女性化 / 男性化 / 其他；儿童 / 青少年（变声期）/ 成人 / 长者——影响默认靶标、音区边界与参考口径；
- **训练靶标**：设定目标基频区间（新装默认 120–220 Hz 中性区间，按训练方向铺底的预设见参数说明书）后，测试页实时显示偏差与达成率。达成率长期 <20% 说明目标过高（先调低），>90% 可以加难度；
- **基线记录**：开始系统训练当天录一条作为基线，之后每条记录自动与它对比；建议每月滚动更新一次；
- **共振峰目标区**：设定目标 F1/F2 中心与半径，用于元音落点命中率；
- **自定义音区边界**：四个分界点划分五个音区，适配变声期、童声、低音女声；
- **实时练习视图**：实时元音落点 / 实时音高 / 实时语谱 / 实时声域图，说话时直接看 F1/F2 移动、音域包络与频谱；监听模式不保存录音；
- **练习提醒**：每日固定时间本地通知提醒录一条；当天已有记录则不打扰。注意：提醒在应用打开或后台运行时生效，应用被完全关闭后无法唤醒（无推送服务的平台限制）。

## AI 功能

- **大模型**（设置 → 大模型）：配置任意 OpenAI 兼容接口（Base URL / API Key / 模型 ID），支持多个配置档与 Anthropic 接口，可「测试连接」；档案里可一键从 `/models` 拉取模型列表，并按接口返回的元数据或内置目录自动识别上下文长度（可手动改；接口未开放 CORS 时请手动填写模型 ID）；Token 用量按功能统计，费用自动估算（优先服务商 `/models` 单价，失败回退内置目录）；训练建议 / 周报仅上传统计指标与备注（AI 助手另含对话文本、选中的记忆与内置文档片段；均不含音频），请使用可信接口；
- **记忆**（设置 → 大模型 → 记忆）：跨对话保留的事实 / 偏好 / 要求 / 注意，可置顶或从最近对话提取；只存本机、不随设置导出，使用时随助手请求发送（可在 AI 请求日志中查看实际内容）；
- **提示词**（设置 → 大模型 → 提示词）：给 AI 建议追加补充规则（如「优先评估共鸣」），或整体覆写内置提示词；
- **AI 周报**：历史页趋势视图底部，一键把近 7 天聚合统计交给大模型出周总结；
- **AI 助手**：见上文「AI 助手」一节；它会自动带上你的记录统计摘要，并检索应用内置文档来回答参数问题；
- **快捷提问**：空对话、已配置接口、有记录且无有效缓存时，会在后台自动发一次小请求，用最近记录摘要与训练目标生成建议问题（可能产生少量 API 费用；失败时静默退回本地问题；点击建议只填入输入框，不自动发送）；
- **AI 翻译**：界面里缺的翻译可由大模型自动补齐（设置 → 语言）。

## 高级（设置 → 高级）

- **分析页语谱图 / 实时频谱**：更多可视化（额外耗电）；
- **音高算法对比**：分析页对保存过音频的记录用 pYIN / MPM 重算基频，并与录音时的 YIN 曲线叠加对比（实时检测器固定为 YIN；设置项仅保留在重算指纹里）；
- **算法参数微调**：YIN 阈值、音高上下限、预加重、LPC 阶数、共振峰搜索窗等；
- **脚本中心**：用 Lua 脚本自定义四类行为——建议规则（可多开合并）、分享卡模板、声之花生成、自定义导出格式。脚本按方向分组为胶囊：点按启用、长按看详情与试跑；分享卡 / 花朵 / 导出方向同一时间只生效一个脚本，导入单个 `.lua` 文件会自动识别方向。内置示例丰富，可试运行预览与全量自检；

> 自定义音区边界与实时练习视图已归入 设置 → 训练；外部音频导入在 设置 → 数据。重新分析在分析页右上角。

## 数据管理（设置 → 数据）

- 导出 / 导入 JSON（全量记录）、设置单独导出（不含 API Key、记忆、导出模板与 Lua 脚本）、帧级 CSV、交互式 HTML 报告、临床报告、MIDI、Praat 格式、自定义导出模板与 Lua 导出脚本；
- 本地自动备份：选择文件夹后按天写入（实验性）；
- GitHub 云备份：Device Flow 连接自己的私有仓库；
- WebDAV 云备份：连接任意 WebDAV 服务（坚果云等）；
- 备份加密：为云备份设置口令（AES-GCM），并支持自动锁定；开启后可选择用同一口令加密手动 ZIP（导出为 `.svtz`）与本地自动备份，未解锁时自动备份会暂停；
- 备份完整性检查：选择 ZIP / 加密 `.svtz`，校验能否解密、`records.json`、版本、记录字段与音频数量；显示上次验证时间，并可做不写入资料库的恢复演练；
- **本地只读 API（桌面版）**：在 设置 → 数据 手动启动，于 `127.0.0.1:47821` 提供 `/records`、`/trends`、`/export`，需要 token；只读、默认关闭、关闭应用即停止。另附 `svt` CLI，详见仓库 `documentation/GUIDE-LOCAL-API.md`；
- **AI 请求日志**：数据页内的独立子页——按日期分组列出功能 / 模型 / 域名 / 体积 / 摘要，点开查看完整请求体，可复制、可清空（只留最近 10 条；超过 4000 字的消息会截断显示；日志写入失败不影响请求本身，也不含 API Key）；
- **局域网同步**：两台设备在同一 Wi-Fi 下直连互传记录与音频，全程不经服务器；默认一端显示二维码、另一端用相机扫描，没有相机或页面不是 HTTPS 时可复制粘贴连接文本；最近同步设备会被记住；
- 外部音频导入：把手机录音 / 微信语音拖入分析，安装为应用后支持系统「分享到」；
- 载入示例数据（无麦克风体验用）、清除全部数据；
- 数据流向说明（隐私政策）：[privacy-policy.md](privacy-policy.md)，也可在 设置 → 关于 查看。

## 隐私与安全（设置 → 隐私与安全）

- **应用锁**：打开 App 或回到前台时需要 6 位 PIN；可另开生物识别。Android 强生物识别可重置 PIN；Windows Hello 与 WebAuthn 只用于解锁，重置 PIN 需要恢复码。冷启动、后台超过 5 分钟、点「立即锁定」或按 `Ctrl/⌘+Shift+L` 都会重新上锁；
- **第二 PIN（诱饵模式）**：可另设一个 6 位 PIN，输入后只打开一个空的演示资料库，不显示真实记录；真实 PIN 才进入真实数据。它是界面层安全模式，不是加密，真实数据仍在设备上；可选的「紧急清除」开启前需要二次确认，开启后输入第二 PIN 会删除本机数据并重载应用；
- **恢复码**：20 位一次性恢复码，只展示一次，只保存哈希；忘记 PIN 时用它重置。改 PIN、重置 PIN 后旧码立即作废，必须保存新码；没有可重置 PIN 的强生物识别时恢复码为必填；
- **失败延迟**：连续输错 5 次后 30 秒，之后每 5 次翻倍，上限 1 小时；不会自动清空数据；
- **隐私屏幕**：切后台时用纯色遮住内容；Android 可另开「禁止截屏」（会同时禁止截屏和最近任务预览）；
- **低调模式（Android）**：在 Voice Notes / Vocal Log / Audio Journal 三个中性桌面名称与图标之间切换；切换会重启 App，桌面图标/名称可能需要几秒更新；低调模式下练习提醒会暂停，避免通知暴露应用名称；
- 锁凭据与恢复码只保存在本机 IndexedDB，不进入设置导出、云备份或局域网同步；生物识别由系统处理，应用不接触指纹/面容原始数据；
- 忘记 PIN 且生物识别/恢复码都不可用时，锁屏提供「清除所有数据」；该操作不可撤销。

## 外观与语言（设置 → 外观 / 语言）

- 主题：莫奈取色（跟随主题色相滑条）、跨性别骄傲旗固定配色，或自定义背景图片；浅色 / 深色 / 跟随系统；
- **导航栏**：三种样式，在 设置 → 外观 里切换——悬浮胶囊（默认，4 个页签 + 录音圆球）、贯穿底部的经典底栏（5 个页签，含 AI 页签，录音键改为测试页扇形键）、AI 工作台（隐藏底栏，助手独占全屏）；
- 彩蛋：特定声线触发主题音染与音量呼吸等效果；
- **主题分享**：把整套外观打包成 `.svt-theme` 文件导出 / 导入（背景图只带参数，不带图片本体）；花园布局（每行花数 / 是否按月分节）也在这里；
- 界面语言：简体中文、繁體中文、English、日本語、Español、Français、文言（華夏）七种，外加「AI 翻译」；支持自定义词条。

## 必要说明（请务必阅读）

1. **不构成医学诊断**。所有参考范围来自常见嗓音科学文献的近似值，未经临床验证；若出现喉痛、压迫感、持续嘶哑，立即停止训练并就医。
2. **数据只能和自己比**。受麦克风、距离、环境影响巨大；请固定设备与录音条件做纵向追踪，换设备后请重新录基线。
3. **嗓音质量四项是安全线**：Jitter / Shimmer / HNR / CPPS 变差 = 声带在受累。四项一起变差说明练习过量，先休息；单次异常没有意义，看趋势。
4. **长音与朗读的数据不可比**，趋势图请按模式过滤。
5. **AI 建议由大模型生成**，仅供参考，不构成医学建议；分析标准与参数说明书的口径一致，可在提示词页补充你自己的规则。
6. **录音属于敏感个人信息**，本应用不联网上传；如担心设备被翻看，可在设置中为云备份启用口令加密，或考虑浏览器隐私模式使用（数据不落盘）。
7. 响度未经绝对声压校准（dBFS），只反映相对强弱。

## 常见问题

- **嗓音质量显示「—」**：未开启「保存录音音频」，或该记录早于该功能；
- **提示数据无效**：录音太短、有效发声占比过低、响度异常（离麦太远或削波）；
- **AI 相关功能不可用**：先到 设置 → 大模型 填写接口并「测试连接」；
- **参考分和音区色带为什么对不上**：色带按可自定义边界逐帧着色（默认 85 / 165 / 180 / 255 Hz）；参考分用固定感知锚点（<130 / 145–175 / >180 Hz）综合整段音高与共鸣，两者口径不同，不矛盾；
- **想看某个参数的详细解读**：仓库 `documentation/PARAMETERS-GUIDE.md` 有全部参数的物理含义、参考区间与训练意义。
