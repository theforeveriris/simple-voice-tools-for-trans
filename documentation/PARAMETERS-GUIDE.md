# 参数说明书:每一个参数反映什么

本文档逐项解释 Simple Voice Tool for Trans 的全部测试参数:它物理上是什么、应用如何测量、数值升高或降低各反映什么、听感上对应什么、对跨性别声音训练(MtF 女性化 / FtM 男性化)分别意味着什么。

> **必读声明**
> 1. 所有数值仅供自我追踪,不构成医学诊断。文中"参考范围"来自常见嗓音科学文献的近似值,未经临床验证,个体差异很大。文献出处统一见 [REFERENCES.md](REFERENCES.md)。
> 2. 数据受麦克风、距离、环境影响。**唯一有效的比较方式是固定条件下的纵向对比(和自己比)**,换设备/换环境后的数据不可直接比。
> 3. 若出现喉痛、压迫感、持续嘶哑,立即停止训练并就医。数据变差往往早于听感变差。

## 一、音高维度

### 1.0 基频 F0 的物理与生理基础

F0(Fundamental Frequency,基频)是声带每秒完成振动周期的次数,单位 Hz。它是"音高"的物理载体:男声声带长而厚,振动慢(约 85–180 Hz);女声声带短而薄,振动快(约 160–255 Hz)。声带长度由青春期激素决定,所以**F0 有生理底子,但环形肌/甲杓肌的协调、喉位、气息都可以训练**——这就是跨性别voice training 可行性的物理依据。

**应用怎么测**:YIN 算法,对每一帧波形做累计均值归一化差分后找第一低于阈值的谷(实时约 60 帧/秒,落库与离线管线 30 帧/秒),输出频率与置信度;只有电平高于「发声门限」(默认 −55 dB,实验性可调)的帧才计算(静音不猜)。YIN 的置信度不单独做发声判定(它参与嗓音质量与频谱嗓音指标的门限),因此低置信帧仍可能给出 F0 值——曲线上的"未检出"缺口有三个来源:电平低于发声门限、最小 CMND 超过「放弃阈值」(阈值 + 0.31;默认 0.45,约合置信度 < 0.55),或插值后的频率落在音高搜索范围之外。pYIN / MPM 已内置但**设置界面没有开关**(见文末「音高算法与对比卡」)。

**曲线怎么看**:
- **颜色** = 所在音区(淡紫=偏低/偏高、淡蓝=男声区、黑=过渡区、淡粉=女声区;边界可在 训练 自定义);
- **海拔** = 音高高低;
- **斜率** = 语调走向(疑问句尾上扬、陈述句尾下沉,都是正常语调);
- **缺口** = 停顿或未检出(说话时正常;长音模式的缺口说明断音)。

### 1.1 平均基频(avgF0)

**反映什么**:这段录音音高的重心。它是最直观的"我现在整体在什么高度"。

- **偏高意味着**:整体向目标区靠拢(对 MtF 是进步),但也可能是紧张性抬喉——需结合 Jitter 看是否"硬拔"。
- **偏低意味着**:回落到习惯音区(常见于朗读走神、疲劳、感冒),或刻意压低。
- **感知映射**:听者对"男声/女声"的第一判断强烈依赖会话平均 F0。跨性别研究常用约 155–165 Hz 作为感知分水岭:持续高于它,声音才"有机会"被听成女声;低于它几乎必然被听成男声。
- **MtF 意义**:日常会话通常以 **165–220 Hz** 为阶段性目标(应用新装默认靶标为 120–220 Hz 的中性区间,首次引导选择 MtF 方向会自动铺底为 165–255 Hz,可自行收窄)。注意平均值是"重心",句尾掉音会掩盖进步——配合 P10 看。
- **FtM 意义**:激素一般会把平均 F0 自然带入 85–130 Hz;训练意义在低音的稳定与不漏气,而非继续硬压(压喉伤声带且听感闷)。

### 1.2 中位基频(medianF0)

**反映什么**:把全部有声帧 F0 排序后取中间值——"典型时刻的音高"。

- 与平均值的差异本身就是信息:**中位 ≈ 平均** → 音高分布对称;**中位 < 平均** → 少数尖 叫/上扬帧拉高了均值,多数时间其实在低处;**中位 > 平均** → 反之,多数时间在高处,偶尔掉音。
- **训练意义**:日常追踪**优先看中位数**。它对"偶尔一声高音"免疫,比平均更诚实。一个"平均 175 但中位 155"的声音,实际听感比数据表面更偏男——这种均值/中位倒挂是"练习时抬上去、说话时掉下来"的典型数据特征。

### 1.3 最低 / 最高基频(minF0 / maxF0)

**反映什么**:这段录音中出现的音高极值(单帧)。

- 它们是**触点而非能力**:可能是咳嗽余音、笑音、清嗓的伪迹。单看意义有限。
- **有价值的用法**:maxF0 反映"放松状态下自然冒出的高音能力"——如果 maxF0 能轻松到 250 Hz+,说明声带具备女声区振动能力,问题只在"稳定住";minF0 在 MtF 追踪中如果逐月抬升(比如 98 → 130),提示整体音区在迁移。
- **注意**:极值噪声大,永远和 P10/P90 对照着看。

### 1.4 P10 / P90(工作音域上下沿)

**反映什么**:去掉前后各 10% 极端帧后,90% 的时间你的音高活动在 P10–P90 这条带里。**这是全部音高统计里对"听感"最有效的单一指标**。

- **P10 偏低意味着**:你会长时间掉到低音区——听感上就是"说着说着破功"。MtF 常见病灶:句尾助词、句号下沉时掉回 120–150 Hz。
- **P90 偏低意味着**:语调上限打不开,声音"平、闷、没活力"。
- **训练意义**:
  - MtF 阶段目标示例:P10 从 120 → 150 → 175,P90 从 190 → 220 → 240。P10 抬不上去时,专门练"句尾不回落"(朗读同一句话,刻意让最后一个字不低于靶标下限)。
  - P10–P90 的**带宽**也有意义:太窄(<30 Hz)即使位置对,听起来也是单调的"机器人女声";自然女声朗读带宽通常 ≥50 Hz。

### 1.5 基频标准差(stdF0)

**反映什么**:音高围绕平均值的波动总量,即**语调丰富度**。

- **过低(<约 10 Hz,朗读场景)**:平直单调。听感是"机器人""平板"。很多 MtF 练习者把全部注意力放在"别掉下去"上,结果把语调压死——stdF0 就是这个错误的报警器。
- **过高(>约 40–50 Hz,朗读场景)**:波动失控,可能每句都在跳,或含大量情绪性起伏;也可能只是样本里有笑 叫。
- **区间为宜**:自然朗读大致 15–35 Hz(因语言与文本而异,务必只和自己比)。
- **FtM 意义**:男性语调同样有起伏,但基线更低;追求"稳定低音"时不要把 stdF0 压到 0,否则同样单调。
- **注意**:stdF0 只在**朗读模式**有语调意义;长音模式 stdF0 应接近 0(那是"音高稳定度"指标,见长音分析)。

### 1.6 音高偏差(cents,顶部概览卡)

**反映什么**:当前选中区间的平均基频偏离**最近的十二平均律半音**多少音分(100 cents = 一个半音,±50 cents 以内视为"贴音")。

- **训练意义**:比 Hz 更符合听感的细粒度标尺——人耳按等比(音分)而非等差(Hz)感知音高。把平均 F0 从"离目标音差 80 cents"练到"差 20 cents",就是音高稳定性的进步;它也方便跨音高比较(180 Hz 处的 30 cents 与 220 Hz 处的 30 cents 听感距离相同)。
- **注意**:它描述的是"离标准音多远",不是"离靶标多远";靶标反馈看达成率与测试页的 Hz 偏差提示。

### 1.7 靶标达成率(inTargetPct)

**反映什么**:有声帧落在目标区间内的百分比。每日主指标。
- **偏低**:音高目标对当前阶段过高(达成率长期 <20% 会挫败且易伤嗓,先调低靶标,练稳了再逐 10 Hz 上调);
- **偏高(>90%)**:该加难度了。
- **注意**:达成率不管共鸣与语调,F0 在区内 ≠ 听感正确;它只是音高维度的"出勤率"。

### 1.8 男声区 / 过渡区 / 女声区占比

**反映什么**:有声帧落在三个音区的时间比例(边界默认 85 / 165 / 180 / 255 Hz,可自定义,适配变声期/童声/低音女声)。
- **训练意义**:一张"时间去向图"。MtF 常见轨迹:前期女声区 20% → 中期 60% → 后期 90%+。过渡区占比大说明你常年在"骑墙",边界感尚未建立。
- **坑**:①它只统计音高,共鸣再差也算"女声区";②默认边界对低音女性/高音男性不公平,先按自己情况调边界;③和达成率高度重叠,选一个盯即可。

## 二、共振峰维度(共鸣)

### 2.0 原理速览:声源-滤波模型

声带振动产生的是"嗡嗡"的蜂音(声源),经过咽喉-口腔-鼻腔组成的管道(声道)被滤波放大,才变成有辨识度的人声。**声道不同频率的放大峰就是共振峰 F1、F2、F3……**。声带决定 F0(音高),声道形状决定共振峰(共鸣)。这解释了两件事:
1. 为什么 MtF 练共鸣比练音高更有性价比——声道形状纯靠肌肉姿态,无生理上限;
2. 为什么 F0 一样高的两个人,一个听感女一个听感男——共振峰不同(女性声道短,共振峰整体频率更高)。

**应用怎么测**:LPC 线性预测编码(预加重 → 低通抽取 → Levinson-Durbin 求解 + 多项式求根),每 2 帧算一次并做指数平滑;只接受 F1 ∈ [`f1MinHz`(默认 200,可调 100–400), 1100] Hz、F2 ∈ [max(F1+150, 700), `f2MaxHz`(默认 3400,可调 2000–5000)] 且带宽 < 700 Hz 的候选根,无声帧不猜。预加重系数与 LPC 阶数(默认自动 = 2 + 采样率kHz)同样可在 高级 调整——见文末「实验性算法参数」。

### 2.1 F1(第一共振峰)

**物理意义**:与**开口度**正相关——下巴越打开、口咽腔越大,F1 越高。元音「a」F1 最高(全开),「i」「u」最低(闭)。

**典型参考值(发「a」,因人而异)**:男性约 700–800 Hz;女性约 850–1100 Hz。

- **偏高意味着**:开口更大/咽腔更收紧(对 MtF 发「a」是**核心训练指标**——抬高 F1 是"共鸣女性化"最直接的量化体现);
- **偏低意味着**:开口小、声音"闷在嘴里"、咽腔松弛——听感"沉、厚、男"。
- **训练意义**:
  - MtF:长音「a」的 F1 从 700 练到 850→900→950+,每 +50 Hz 都是可庆祝的里程碑。常用手段:提颧骨(微笑位)、软腭上抬、"打哈欠前半程"的咽腔收紧。**F1 提升伴随 F0 平稳、Jitter 不恶化,才是有效提升**。
  - FtM:自然即可,刻意压 F1 会闷。
- **坑**:F1 只在**有声且元音明确**的帧可靠;辅音与气声帧的 F1 是噪声。看「长音 a」或朗读中拖长的元音段最有意义。

### 2.2 F2(第二共振峰)

**物理意义**:与**舌位前后**强相关——舌越靠前(「i」)F2 越高,越靠后(「u」)F2 越低。它也受唇形影响(拢唇压低 F2)。

**典型参考值(发「i」)**:男性约 1900–2300 Hz;女性约 2600–2900 Hz。这是全部元音中**性别差异最大**的共振峰——所以「i」是共鸣训练的试金石。

- **偏高意味着**(发 i 时):舌位前、声道前腔收窄——正是 MtF 想要的"前位共鸣";
- **偏低意味着**:发声位置靠后、拢唇、舌根后缩——听感"靠后、厚"。
- **训练意义**:MtF 可用长音「i」追踪 F2,目标从 2000 上下向 2500+ 推进;说话练习中保持"舌头积极、接触点靠前"(前鼻音 n、边音 l 是自检点)。
- **坑**:F2 对唇形极敏感,测试时别刻意拢唇或咧嘴过度,保持自然、可复制的表情。

### 2.3 F1 / F2 波动范围(f1Range / f2Range)

**反映什么**:整段录音中共振峰的最小-最大区间,即**你在不同元音间切换的幅度**。

- **过窄意味着**:整段话接近单元音(语速过慢、吐字含糊),或共振峰检测质量差;
- **正常**:朗读包含多样元音,F1 波动 200–500 Hz、F2 波动 500–1500 Hz 量级都正常;
- **训练意义**:与 stdF0 呼应——"语调别死"的共振峰版本是"吐字别糊"。MtF 练习者若只顾维持共鸣姿势,容易吐字变僵,波动范围收窄是信号。

### 2.4 F1 / F2 比值

**反映什么**:全部有声帧 F1 均值与 F2 均值之比,粗略的"开口/闭合倾向"参考。它不对应单一生理量,只是个组合指标:开口大的元音(a 类)比值高,闭元音(i/u 类)比值低。看趋势即可,勿深究绝对值。

### 2.5 元音空间散点(含质心)

横轴 F2(**左 = 前**),纵轴 F1(**上 = 开口小**),每个有声帧落一个点,密度即驻留时长;×为散点质心(平均位置),虚线圈为 i / a / u 参考元音位置。

- **反映什么**:你的"元音口音地图"。云的位置 = 你习惯的共鸣布局;云的形状 = 吐字多样性(圆胖=元音丰富,瘦条=单调)。
- **MtF 读法**:与参考元音圈对比——女性化的元音布局整体**更高更前**。训练见效时,能看到整片云朝右上方向迁移;对比视图中两条记录的云叠加 + 质心位移,是最直观的"前后对比图"。
- **注意**:散点混有辅音过渡帧,边缘毛刺正常;关注**云的主体**而非个别离群点。
- **参考点口径**:散点图只画 i / a / u 三个**视觉参考点**(Peterson & Barney,1952);而「声音性别表达参考分」用 H95 的 12 个美式英语元音,「长音元音检查」用普通话 6 个主元音(Meng et al.,2006)。三套参考的语料与用途不同,**不要混用**;完整说明见 `documentation/ALGORITHM-VOWEL.md`。

### 2.6 F2−F1 间距(f2f1GapHz / f2f1GapMedianHz)

**怎么算**:只取 **F1/F2 同帧检出**的有声帧,逐帧计算 F2 − F1(逐帧相减而非均值相减,避免把不同帧的开口状态与舌位错误配对),给出均值与中位数。旧记录无此字段,用「重新分析」可补算。

**反映什么**:**共鸣空间**——F1 越低(开口收小、喉位平稳)且 F2 越高(舌位靠前),间距越大,元音空间整体前移。这是女性化共鸣训练的核心量化:文献常引 **≥1000 Hz** 为女性化参考线(出处见 REFERENCES.md)。

- **MtF 读法**:间距逐周走高 = 共鸣在收前。配合元音散点看云的迁移方向,两者应一致。
- **FtM 注意**:方向相反,勿以此为目标。
- **局限**:混入辅音过渡帧会拉低数值,看**趋势**不看单次。

### 2.7 谱倾斜(spectralTiltDbOct)

**怎么算**:有声帧幅度谱在 200–5000 Hz 频段内,对 log2(频率) 做最小二乘回归的斜率(dB/octave),取帧均值。需录音音频(离线管线计算),旧记录用「重新分析」可补算。

**反映什么**:**音色明暗**——负得越多(如 −8 dB/oct),高频衰减越快,听感越"暗/闷/气";接近 0 则明亮、穿透。它与 F2 高度相关但更整体(包含 F3 以上的能量分布)。

- **训练关联**:共鸣前移、喉位上提通常使倾斜变平(变亮);气声增多使倾斜变陡。
- **局限**:受录音增益与麦克风频响影响,只宜与自己纵向比。

## 三、能量维度

### 3.0 RMS 与 dB 的口径

应用显示的分贝是 **dBFS**(相对麦克风满量程,负值,0 = 数字削波),**未经绝对声压校准**:它反映"录音里信号的相对强弱",不是真实声压级。所以响度参数**只能自己和自己比**(同设备、同距离)。

### 3.1 平均响度(avgDb)

**反映什么**:只统计电平 ≥ 「活跃门限」(`activeGateDb`,默认 −50 dB,实验性可调)的"发声帧"的平均音量(静音帧不拉低均值)。

- **过低(如 < −35 dB)**:音量小、气声重,或离麦克风远——会连带恶化共振峰与音质检测质量;
- **过高(> −10 dB)**:接近削波,失真,数据失真;
- **舒适区**:大约 −30 ~ −15 dB。
- **训练意义**:本身不是跨性别训练目标,但是**数据质量守门员**:所有参数的可靠性都建立在响度合理之上。会话响度也是"自信度"的外显——MtF 初期常不自觉减小音量(怕暴露),数据会如实显示。

### 3.2 峰值响度(peakDb)

**反映什么**:录音中最响的瞬间。用于检查是否削波(接近 0 dB = 削波风险),以及音量控制是否稳定(峰谷差过大 = 忽大忽小)。

### 3.3 有效发声占比(voicedPct)

**反映什么**:检出有声帧占总帧数的比例 = **说话连贯度**。

- 朗读场景 <50%:停顿过多、句读破碎(紧张、忘词、习惯性断句);
- 长音场景应 >95%:偏低说明断音,MPT 与 CV 不可信;
- **训练意义**:间接反映流畅度与自信度;同时它决定其他统计的样本量——占比过低时,音高统计的代表性都打折。

### 3.4 录音时长 / 采样帧数

元信息:时长(秒)、总帧数、采样率(sampleHz,约 30 Hz)。用途是判断统计可信度:帧数太少(<30 帧)的记录,统计波动大,不宜与长录音比较。

## 四、嗓音质量维度(Jitter / Shimmer / HNR / CPPS)

### 4.0 共同前提

- 需要**开启「保存录音音频」**(由录音离线计算),旧记录显示「—」;
- 这四项是**嗓音健康监测器,不是训练目标**。共同规律:**变差 = 声带在受累**;它们是安全红线,也是"练习强度是否过量"的客观仪表;
- 需要长音或连续语音才有意义;受感冒、疲劳、咖啡因、环境影响大,**单次异常没有意义,趋势才有意义**。

### 4.1 Jitter(基频微扰,%)

**是什么**:相邻声带振动周期**时长**的微小变异率。理想化的声带每周期时长完全一致(Jitter→0),真实人声总有不规则。

**应用怎么测**:峰检测提取周期序列 + 抛物线细化,128 ms 窗内至少 `vqMinPeriods`(默认 8,可调 4–16)个周期且帧置信度 ≥ `vqMinProb`(默认 0.55,可调),相邻周期比超过 ±25% 视为八度跳变剔除,结果封顶 5%。

**参考**:健康成人通常 **< 1%**(安静、放松发声时常见 0.2–0.5%)。

**升高反映什么**(按可能性排序):
1. **发声姿势勉强**——对跨性别训练最常见:MtF 硬抬音高、长期勉强维持头声/假声边界,声带闭合与张力不协调,Jitter 随之升高。这是"当前目标超出当前能力"的客观信号;
2. 疲劳、用声过量(练太久);
3. 紧张、焦虑(喉部肌肉紧张);
4. 器质性变化(结节、息肉等)——**持续 >2–3% 且休息后不回落,应就医**。

**FtM 注意**:激素变声期(音质重构期)Jitter 暂时升高属常见现象;变声稳定后仍高才需要关注。

### 4.2 Shimmer(振幅微扰,%)

**是什么**:相邻振动周期**幅度**的变异率。**应用内封顶 15%,健康成人通常 < 4–5%**。

**升高反映什么**:
1. **声门闭合不良 / 气声过多**——声带闭合不严,每周期漏气量不同;
2. 气息支撑不足(长句尾段尤其明显);
3. 同 Jitter:疲劳、勉强姿势、器质性问题。

**与 Jitter 的分工**:Jitter 管"时间维"的乱,Shimmer 管"幅度维"的乱。两者同时升高 = 声带振动整体失稳;只有 Shimmer 高而 Jitter 正常,更倾向气息/闭合问题而非音高控制问题。

### 4.3 HNR(谐噪比,dB)

**是什么**:谐波能量(乐音成分)与噪声成分之比。**越高越"干净"**。

**应用怎么测**:由归一化自相关峰值换算(对齐 Praat Harmonicity 口径):在 YIN 检出的基频周期附近搜索自相关峰值 r,HNR = 10·log10(r/(1−r))。干净信号 r→1 时钳制在 40dB。**趋势可信、绝对值与 Praat 有 dB 级差异(窗相关 vs 直接自相关)**——交叉验证实测多为 1–7 dB,个别元音样本可达 15 dB(见 `VERIFICATION-REPORT.md`)。

**参考**:健康成人约 **20 dB 以上**;明显低于 15 dB 通常对应可听见的嘶哑或气声。

**降低反映什么**:噪声成分增加——气声过重(闭合不良)、喉部紧张、感冒鼻音、环境噪声混入。对 MtF:**刻意"用气声包高音"是常见误区**,气声能暂时掩盖音高不足,但 HNR 会持续偏低,且长期是喉部负担——正确路径仍是共鸣,不是气声滤镜。

### 4.4 CPPS(平滑倒谱峰突出度,dB)

**是什么**:通过倒谱分析衡量声音的周期清晰度,综合了周期性、噪声、气息感,是**整体嗓音质量的单一趋势线**。**越高越好**。它对连续语音稳健,所以**朗读模式下也有意义**(J/S/HNR 在朗读中会被停顿干扰)。

**应用怎么测**:自写 FFT → 实倒谱 → 峰值减去回归线基线 → 时间平滑(窗长 `cppsSmoothFrames`,默认 5 帧,可调),取**均值**(Hillenbrand 标准口径;不再减标准差)。倒谱峰搜索的基频上限 `cppsF0Max`(默认 500 Hz,可调)与活跃门限同前。与 Praat 存在量级差异(实测约为其 1/21 – 1/3,逐信号不同),绝对数值不可直接比较,相对高低也不保证同向,看趋势即可。

**参考**:无绝对临床阈值(方法依赖),常见连续语音量级在 10–20 dB;**看自己的趋势**:训练强度上调后 CPPS 逐周走低,就是过量的早期信号;回落后稳定抬升,是嗓音适应的证据。

### 4.5 四项联动解读矩阵

| 组合 | 最可能的反映 | 处置 |
| --- | --- | --- |
| J↑ + S↑ + HNR↓ + CPPS↓ | 用声过量/姿势勉强(综合受累) | 减量休息,回退难度 |
| 仅 J↑ | 音高控制勉强(硬拔) | 降低 F0 目标 5–10 Hz 练稳 |
| 仅 S↑ + HNR↓ | 闭合不良/气声过重 | 练气息支撑与闭合,少用气声滤镜 |
| 全部正常但听感差 | 问题不在健康在共鸣/语调 | 看 F1/F2 与 stdF0 |
| 全部变差 + 喉痛 | 立即停练 | 休息,不缓解就医 |

### 4.6 谐波频谱指标(H1–H2 / H2–H4 / H1–A3 / 气声度 / 鼻化)

**怎么算**:离线管线对每个 40ms 窗(10ms 移)做能量 + YIN 置信度门限,汉宁窗 FFT 后对每个谐波在 ±半谐波间距内取局部峰(抗频率对齐误差),跨帧取中位数(气声度取均值)。需开启「保存录音音频」;旧记录可用「重新分析」补算。

- **H1–H2(dB)**:第一谐波与第二谐波的幅度差。随声门开商增大而升高,**偏高提示气声**;与 HNR/CPPS 一起看;
- **H2–H4(dB)**:第二与第四谐波的幅度差,另一条频谱倾斜口径;越高说明高频衰减越快、音色越暗/气声成分越多;
- **H1–A3(dB)**:第一谐波与 F3 区(2–3.5kHz)最强谐波的差——气声的经典指标;A3 用该频带内最强谐波作 F3 代理,不额外做 F3 跟踪;
- **气声度(0–1)**:由 H1–H2 偏高与谐波间噪声偏高合成的综合指数,越大越气声;
- **鼻化(A1−P1,dB)**:A1 为 F1 处谐波幅度,P1 为 300–1000Hz 鼻腔峰;数值越低鼻化越重。

**怎么读**:这些指标没有统一临床阈值,和 J/S/HNR/CPPS 一起**看趋势**。气声长期偏高优先查闭合与气息支撑,不要用气声掩盖音高;鼻化突然升高先排查感冒/鼻塞。单项异常不代表问题。

## 五、长音分析专项

长音(持续发「a」,发声后静音 1 秒自动停止)剥离了语调与吐字干扰,是**嗓音健康与控制力**的净化样本。

### 5.1 最长声时 MPT(秒)

**是什么**:从第一个有声帧到最后一个有声帧的时长——一口气能稳定发声多久。

**参考**:健康成人多在 **15–25 秒**(女性略短于男性;随年龄下降)。

**偏短反映什么**:
1. 气息支撑不足(腹式呼吸未建立);
2. 声门闭合不良(漏气,常伴 Shimmer 高);
3. 测试时紧张,一口气没敢用完。

**跨性别训练意义**:高音高 + 高共鸣姿势都比习惯发声**更费气**。MPT < 10 秒时,先练气息(腹式支撑、缓吸缓呼),再追音高/共鸣目标,否则一切指标都在低气息的泥潭里失真。

### 5.2 音高稳定度 CV(%)

**是什么**:长音期间音高的变异系数(标准差/均值)。**越接近 0% 越稳**。

**偏高反映什么**:
1. 目标音高超出稳定控制范围(最常见的"该不该继续升目标"判据:**在 190 Hz 的 CV 稳不住之前,不追 210 Hz**);
2. 颤音未受控(自然颤音是好事,但失控的抖是问题);
3. 起音犹豫(开头滑上去的过程拉高变异)。

**注意**:朗读的 stdF0 追求"有起伏",长音的 CV 追求"零起伏"——同一个"波动"概念,两个场景目标相反,别看串。

### 5.3 响度衰减(dB/s)

**是什么**:长音过程中音量下降的斜率(对帧电平做最小二乘拟合)。**越接近 0 越平稳**。

**偏高反映什么**:
1. 气息耗尽前没有重新分配压力的能力(尾段"瘪"下去);
2. 声门闭合渐弱(尾段漏气,常与 Shimmer 尾段升高共存);
3. 心理上"不敢撑"。

**训练意义**:与 MPT 配合——MPT 长 + 衰减大 = "能撑但撑得难看";两者同优才是真气息。

## 六、滑音专项:声域图 VRP

滑音模式(低→高滑唱 20 秒)生成 **phonetogram(声域图)**:纵轴是半音音高(C2–C6),横轴是响度,色深 = 在该"音高×音量"格子停留的时间。

**反映什么**:
1. **音域的真实边界**:最亮区域的上下沿 = 你的舒适音域;色块在某高度"断崖" = 换声点/极限;
2. **力度动态**:同一音高能横跨的响度宽度 = 控制自由度;
3. **练习痕迹**:每周滑一次,色图变化就是音域扩张的直观记录。

**跨性别训练意义**:
- MtF:追踪高音区是否被逐步"点亮"——很多练习者的色图最初止步于 220 Hz 附近,数月后墨迹爬升到 260+;
- 断崖位置即真假声换挡点,日常说话若必须绕开某段音高,听感会不自然——VRP 让你看见这个"绕行区";
- **注意**:响度未绝对校准,横轴只在自己内部比较。

## 七、训练追踪参数

### 7.1 基线对比 Δ(分析页)

在 设置 → 训练 里指定某条历史记录为基线后,新记录自动显示各指标与基线的差值(含音高、音域、响度与嗓音质量)。

**用法**:开始系统训练当天录一条"训练前基线"。之后每个 Δ 都是"这一阶段练习的总效果"。建议每月滚动更新一次基线(旧基线的差距拉太大后,百分比变化会失真)。

### 7.2 趋势图与用声日记(历史页)

- 趋势图:平均基频 + P10–P90 带随日期的变化——**看带的整体迁移,不要看单日点**;
- 日记热力图:练习连续性(频率本身就是最大变量);可按测试模式过滤(长音与朗读的基频不可比)。

### 7.3 对比视图(两两对比)

选两条记录对比:Δ 指标表(量化前后差)、按相对时长对齐的音高曲线叠加(形态对比)、元音散点叠加(共鸣云迁移,× 为各自质心)。这是"复盘"工具:进步与退步都给出像素级证据。

### 7.4 共振峰目标区(设置 → 训练)

指定目标 F1 / F2 中心与容差半径(新装默认 800 / 1700 Hz、半径 200 Hz 的中性共振位;元音「a」的参考位约在 730 / 1090 Hz,可自行设定)后:

- 元音散点图(分析页与测试页实时落点视图)叠加目标矩形;
- 实时统计**落点命中率** = F1/F2 同帧检出且都落在目标 ± 半径内的有声帧占比。

**用法**:共鸣训练版"达成率"。把目标区放在你想稳定的元音位(如女声「a」的 F1≈900),命中率随练习上爬,就是共鸣姿势在固化的直接证据。命中率实时计算、不落库,想留存就靠趋势截图或重算对比。

## 八、组合解读:参数联手说明什么

单一参数有歧义,组合起来才接近真相:

| 数据组合 | 最可能的解释 | 对应动作 |
| --- | --- | --- |
| 平均 F0 达标,但 P10 很低 | 句尾/句中回落,"破功" | 练句尾不回落;盯中位数 |
| F0 达标,听感仍偏男 | 共振峰未动(F1/F2 偏低) | 共鸣训练,盯长音 a 的 F1 |

| stdF0 极低,音高全达标 | 语调被压死(机器人感) | 放开语调,朗读夸张化练习 |
| Jitter 升,其余尚可 | 音高/姿势勉强的早期信号 | 目标回调 5–10 Hz |
| Shimmer↑ + HNR↓,Jitter 正常 | 闭合不良/气声过重 | 气息与闭合练习 |
| 四项全恶化 | 用声过量或身体状态差 | 停练休息;持续不恢复就医 |
| avgDb 持续偏低 | 音量小/气声/离麦远 | 先解决录音质量再看其他 |

| 元音云窄且靠后下 | 共鸣位置后、吐字僵 | 前位共鸣 + 吐字多样化 |
| 达成率长期 <20% | 靶标超出当前阶段 | 调低靶标,小步上移 |

## 十、常见问题

**Q:为什么我朗读的平均 F0 比自我感觉低?**
朗读会不自觉回落习惯音区。练"起音即达标":开口第一个字先落靶标内;用中位数与达成率(而非平均值)追踪真实情况。

**Q:换了手机/麦克风,数据全变了?**
正常且必然。请固定设备+距离+环境做纵向追踪;换设备后重新录基线。

**Q:共振峰曲线缺口多 / 语谱图看不懂?**
缺口 = 静音或未检出帧(正常);语谱图横向亮带是谐波、亮团是共振峰轨迹。另注意长录音的语谱图仅覆盖开头部分(应用已知限制,曲线与统计覆盖全程)。

**Q:嗓音质量显示「—」?**
未开启「保存录音音频」;或声音过低(约 60 Hz 附近)导致检测窗口内周期不足;或该记录早于 CPPS 功能。

**Q:参数都好但自己听着还是不满意?**
数据覆盖音高/共鸣/健康三维度,但语调习惯、措辞、叙事节奏等"说话方式"不在量化内。数据是地图不是风景,最终以录音回放的听感为准。

**Q:数值能用于医疗诊断吗?**
不能。阈值未经临床验证;嗓音障碍请咨询耳鼻喉科与言语病理师。

## 十一、实验性算法参数与进阶功能

设置 → 高级 → **算法参数** 收录了 13 项 DSP 参数,供进阶用户微调检测行为。
改动**即时生效于实时曲线**;保存过音频的历史记录可用当前参数**重算**(见下文)。
不确定时用「恢复默认」一键还原。

| 参数 | 默认 | 可选范围 | 作用 |
| --- | --- | --- | --- |
| YIN 判定阈值 `yinThreshold` | 0.14 | 0.05–0.38 | CMND 低于该值才算检出周期;调低更严格(漏检多但误检少),"放弃阈值"随动(阈值 +0.31) |
| 音高搜索下限 `pitchMinHz` | 60 | 40–200 | 低于该频率的周期不搜索(男低音可下调) |
| 音高搜索上限 `pitchMaxHz` | 600 | 300–1200 | 高于该频率的周期不搜索(上限强制 ≥ 下限 +100) |
| 预加重 `preEmphasis` | 0.97 | 0–0.98 | LPC 前的高频提升;0 = 关闭 |
| LPC 阶数 `lpcOrder` | 自动 | 10–22 | 0 = 自动(2 + 采样率kHz,并按帧长钳制);阶数高分辨率高但易伪峰 |
| F1 搜索下限 `f1MinHz` | 200 | 100–400 | F1 候选频率下限(上限固定 1100 Hz) |
| F2 搜索上限 `f2MaxHz` | 3400 | 2000–5000 | F2 候选频率上限 |
| 发声门限 `voicedGateDb` | −55 | −70…−40 dB | 音高检测的最低电平(更低的帧不算音高) |
| 活跃门限 `activeGateDb` | −50 | −70…−30 dB | 响度统计 / 嗓音质量 / CPPS / 共振峰 / 长音静音判停共用的判据 |
| 嗓音质量置信度 `vqMinProb` | 0.55 | 0.3–0.8 | 低于该置信度的帧不参与 J/S/HNR |
| 最少周期数 `vqMinPeriods` | 8 | 4–16 | 128 ms 窗内参与 J/S 计算的最少周期数 |
| CPPS 基频上限 `cppsF0Max` | 500 | 300–1000 | 倒谱峰搜索的基频上限 |
| CPPS 平滑窗 `cppsSmoothFrames` | 5 | 1–15 | CPP 时间平滑帧数 |

### 音高算法与对比卡(实验性)

除默认 YIN 外,内置 **pYIN**(12 档阈值加权投票,抗噪更稳)与 **MPM**(NSDF 最大峰,计算更快)。
设置项 `pitchAlgorithm` 仍然存在(默认 `'yin'`,并参与重算的参数指纹),
但**设置界面目前没有暴露这个开关**,因此正常使用恒为 YIN(导入的旧配置若指定了
pYIN / MPM 仍会生效)。
分析页的「音高算法对比」卡(开关 `pitchCompareEnabled`,默认开)会用 pYIN / MPM
对保存过音频的记录整段重算,与录音时的 YIN 曲线叠加,给出**一致率**(±50 cents 内帧占比)
与**中位音分偏差**——三个算法分歧大,说明该段录音的音高不可靠(常见于气声、噪声环境)。

### 用当前参数重算历史记录

分析页对保存过音频的记录提供「重算」:以当前算法参数在离线管线(32 kHz 统一口径,
超 5 分钟截断)重跑完整分析,先给**新旧统计对比**,确认后才覆盖原记录
(记录带重算时间与参数指纹标记)。调参不再需要重录——录一次,反复试参。

### 外部音频导入

把手机录音 / 微信语音等音频文件拖进应用(或系统「分享到」本应用),走同一套
离线管线生成完整报告(超 5 分钟截断)——参数重算与算法对比同样适用。

## 十二、声音性别表达参考分(VFP 风格)

**是什么**:分析页的 0–100 参考分。它把**中位基频**与**按参考元音归一后的共鸣位置**合成一个连续值:50 附近为中性,越高越靠近女性化参考,越低越靠近男性化参考。概念取自 inaSpeechSegmenter 的 VFP(Voice Femininity Percentage,Doukhan et al., Interspeech 2023),但**不是**其 CNN 模型的输出——本项目在浏览器内只做透明的声学近似。

**完整算法**:音高 logistic、H95 24 点归一、55/45 综合、分档与置信度的推导见 `documentation/ALGORITHM-VOICE-EXPRESSION.md`。

**怎么算**:
- 音高 55%:`medianF0` 经 logistic 映射,中心 155 Hz、宽度 35.3 Hz。**130 Hz → 33 分、180 Hz → 67 分**(恰在三档边界),因此 145–175 Hz 的中性带落在 33–67 之间——与下方参考表和 ASHA 的感知阈值完全一致(早期版本中心 165 Hz / 宽度 20 Hz 会把 145 Hz 算成「男性化」子分,与参考表自相矛盾)。
- 共鸣 45%:**元音归一**后的位置均值(见下)。位置 −1(与男性参考云重合)→ 25 分,0 → 50 分,+1 → 75 分。
- 三档:33 以下=男性化参考,33–66=中性 / 过渡,66 以上=女性化参考。

**元音归一(这版的关键改动)**:早期版本直接把 `F2−F1` 的**绝对值**过 logistic,这是不严谨的——F2−F1 的绝对值强烈依赖说的是哪个元音(说「衣」≈2000 Hz,说「乌」≈570 Hz),同一段朗读里元音分布一变,分数就跟着变,测到的其实是「你说了什么」而不是「你的声音多女性化」。

现在的做法:
1. **元音判定**:把每个有效帧的共振峰与 24 个实测参考点(12 个元音 × 男女)比较,取最近的那个作为归属元音。
2. **位置计算**:落点与「最近的男性参考点」「最近的女性参考点」的距离比值给出连续位置:
   `位置 = (d男 − d女) / (d男 + d女)`,落在男性参考点 → −1,落在女性参考点 → +1,两套等距 → 0。
3. **汇总**:各元音内部按帧聚合,跨元音按时长加权(说话时间占比)。

为什么用「离哪套参考点更近」而不是「先判元音再算位置」:英语元音空间重叠严重——男性 AA 的落点 (F1 756, F2 1309) 与女性 AH 的落点 (760, 1416) 几乎重合,按最近邻判元音会系统性错配;而把 24 个参考点一起比较,天然回避了元音归属的歧义。

**参考值来源**:Hillenbrand, Getty, Clark & Wheeler (1995). *Acoustic characteristics of American English vowels*. JASA 97(5), 3099–3111. doi:10.1121/1.411872 —— 139 名英语母语者、1668 个稳态元音样本的男女分组均值(男 n=45、女 n=48,各 12 个元音)。项目内 12 个元音的男女 F1/F2 参考值见 `src/lib/voiceExpression.ts` 的 `VOWEL_REFS_H95`。

**参考锚点**(训练定向,不是诊断阈值):

| 区间 | 音高 | 共鸣 |
| --- | --- | --- |
| 男性化参考 | F0 < 130 Hz | 位置接近 −1(与男性参考云重合) |
| 中性 / 过渡 | F0 145–175 Hz | 位置接近 0 |
| 女性化参考 | F0 > 180 Hz | 位置接近 +1(与女性参考云重合) |

**与音区色带的关系**:色带是逐帧着色的可自定义边界(默认 85 / 165 / 180 / 255 Hz);本评分用固定的感知锚点(130 / 145–175 / 180 Hz),两者口径不同——色带看「这一帧落在哪」,评分看「整段更接近哪种听感」。因此同一段录音可能出现「男声区占比高,但参考分落在中性」的情况,并不矛盾。

**各元音贡献**:卡片上可展开「各元音贡献」,列出每个元音的时长与归一位置(−1 ~ +1)。这是判断分数被什么拉动的关键:若某个元音的位置明显偏离,说明这一段的落点在该元音上偏男性或偏女性参考。

**怎么读**:
- 看**趋势**,不看单次。F0+VTL 类声学基线对顺性别语料的 VFP 预测 R² 可达 0.94,但对跨性别语料只有约 0.53——音高与共鸣解释不了全部听感(语调、措辞、音质、语境都在起作用)。
- 样本越长越稳:建议 ≥10 秒朗读;短于 3 秒时评分只作提示。长音只代表该元音,不代表说话。
- 变声期、童声、低音女声:别用默认锚点硬套,以自身纵向趋势为准。

**局限**:该分不包含语调、语速、气声、鼻化、发音习惯;元音归一依赖 LPC 共振峰提取的准确度(环境噪声或气声会降低可靠性);也不能替代人耳判断或临床评估。出处见 REFERENCES.md「声音性别感知参考(VFP 风格)」。

### 元音检查(长音自动判定)

**是什么**:长音测试录完后,分析页从稳态段自动判断最接近哪个普通话主元音(a / o / e[ɤ] / i / u / ü[y]),测该段的 F1 / F2 / F0,并与**判定出的同元音**普通话男女参考均值比较。不需要用户预先选择元音;判定不确定时会给出两个候选并标"不确定",不强行给结论。

**怎么判定**:每个元音取「到男性参考」与「到女性参考」中更近的 log-F1/F2 距离作为分数,取分数最低的元音为最佳候选;与第二候选的差距 < 0.06 判"不确定",< 0.12 判"中等置信";离所有参考都超过 0.35(约 42% 的 log 距离)判"未匹配"。位置只在判定出的同一个元音内部比较,−1 = 男性参考均值,+1 = 女性参考均值。

**怎么取数**:只保留 F0 / F1 / F2 同帧有效且 F2 > F1 的帧;找最长连续有声段(容忍偶发丢帧),去掉头尾各 20%,取中段的中位数作为 F1/F2/F0;用 log-F1/F2 的中位绝对偏差判断稳定性(> 7% 提示重录)。位置 = (d男 − d女) / (d男 + d女),−1 = 与男性参考均值重合,+1 = 与女性参考均值重合。

**参考值**:Meng, Chen & Li (2006), PACLIC 20, Table 3——212 名女 + 126 名男播音专业学生,六个主元音的男女 F1/F2 分组均值(见 REFERENCES.md)。参考值是青年播音专业学生的群体均值,不代表所有年龄 / 方言 / 个体;看自己的纵向趋势比看单次位置更有意义。

**怎么读**:每次只发一个元音、保持 1–2 秒平稳;同一个元音、同一设备的前后对比才有可比性。位置接近 0 表示落点落在男女参考之间(两组参考本身有重叠),不是「中性化程度」;卡片不是诊断。完整推导、置信度阈值与三套参考的区别见 `documentation/ALGORITHM-VOWEL.md`。

## 十三、咝音分析(/s/ 频谱重心)

**是什么**:咝音(/s/ /z/ /x/ /sh/ 等摩擦音)的**频谱重心**与音色的性别感知直接相关:重心越高越清亮/靠前,越低越沉/靠后。分析页的「咝音分析」卡会从录音音频里自动挑出摩擦音帧,给出重心中位数与 P10–P90。需开启「保存录音音频」。

**怎么挑帧**:32ms 窗(16ms 移);高频带(4kHz 以上)能量占比 > 55%,且帧电平比该录音中位电平高 12dB 以上,才计为咝音帧(排除底噪与元音)。候选帧太少时放宽电平门限,取高频占比合格帧中电平最高的几帧,保证短促的 /s/ 也有统计。

**参考区间**(按训练方向,中心 ± 半宽,仅供训练参考):女性化取向 **5–10 kHz**(中心 7.5);男性化取向 **2.5–6.5 kHz**(中心 4.5);未指定方向时不显示参考位置。

**怎么读**:
- MtF 常见目标是把 /s/ 从 4kHz 附近往 7–8kHz 推;FtM 方向相反。看**趋势**,别追单次绝对值;
- 麦克风高频响应、齿位、音量、语速都会影响重心;换设备后重新录基线;
- 与 F1/F2 共鸣一起看:如果 /s/ 已经很前但元音仍靠后,说明只练了舌尖、没练咽腔;
- 与嗓音质量一起看:气声过重会把高频能量拉低,让重心虚低,先解决闭合再判断。
