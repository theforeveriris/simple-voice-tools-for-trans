# 声音性别表达参考分算法（VFP 风格）

本文描述分析页「声音性别表达参考」卡片的 0–100 分：它由**音高**与**共鸣**两个子分合成，概念取自 Voice Femininity Percentage（VFP，Doukhan et al., Interspeech 2023），但**不是**其 CNN 模型的输出——本项目在浏览器内只做透明、可复算的声学近似。

> 参考分不构成诊断；50 ≈ 中性，分数越高越接近女性化参考，越低越接近男性化参考。用户的目标由用户定义，分数不替用户设定「应该像什么」。

---

## 一、输入

| 输入 | 来源 | 用途 |
| --- | --- | --- |
| `medianF0` | 整段录音的中位基频 | 音高分 |
| `voicedSamples` / `sampleHz` | 有效发声帧数与序列帧率 | 有效发声时长、置信度 |
| `frames` | 逐帧 `{ f1, f2, durationSec }` | 共鸣分；只在 F0 / F1 / F2 同帧有效且 `F2 > F1` 时进入 |

没有逐帧共振峰时，共鸣分缺失，综合分退化为 100% 音高。长音 / 滑音记录只代表该段发声；判断日常说话请用朗读记录。**长音记录不再显示该综合分**（单音长音不适合 55/45 综合口径），改用「元音检查」卡。

---

## 二、音高分（55%）

中位基频经 logistic 映射：

```text
音高分 = 100 / (1 + exp(-(medianF0 - 155) / 35.3))
```

锚点：

| 中位 F0 | 音高分 | 含义 |
| --- | --- | --- |
| 130 Hz | ≈ 33 | 男性化参考边界 |
| 155 Hz | 50 | 中性中心 |
| 180 Hz | ≈ 67 | 女性化参考边界 |
| 220 Hz | ≈ 88 | 明显偏女性化参考 |

中心 155 Hz / 宽度 35.3 Hz 是刻意选的：它与卡片参考表、ASHA 的「>180 偏女声 / <130 偏男声 / 145–175 中性带」一致。早期版本用 165 Hz / 20 Hz 会把 145 Hz 算成「男性化」，与参考表自相矛盾。

> 顶部 Hero 卡片的「男声区 / 过渡 / 女声区」色带用的是**可配置音区边界**（默认 85 / 165 / 180 / 255 Hz）；本评分用固定感知锚点。两者口径不同，出现「男声区占比高、参考分却在中性」并不矛盾。

---

## 三、共鸣分（45%）

### 3.1 逐帧落点

对每一帧，把它与 Hillenbrand et al. (1995) 的 24 个参考点（12 个美式英语元音 × 男女）比较，距离用 log 空间欧氏距离：

```text
d = hypot(ln(F1 / F1_ref), ln(F2 / F2_ref))
```

- `d男` = 到最近**男性**参考点的距离（跨全部 12 个元音）；
- `d女` = 到最近**女性**参考点的距离（跨全部 12 个元音）；
- `position = (d男 − d女) / (d男 + d女)`，代码钳制到 ±1.5；
- 该帧的元音归属取 24 个点里最近的那个参考点。

**为什么不是先判元音再算位置**：英语元音空间重叠严重——男性 AA 的落点 `(756, 1309)` 与女性 AH 的落点 `(760, 1416)` 几乎重合；先判元音会系统性错配。把 24 个点一起比较，天然回避了元音归属的歧义。

### 3.2 聚合

1. 按元音 code 分组，组内对 `position` 求平均；
2. 各元音组按**时长**加权，得到整段 `positionAvg`（显式用时长，更贴合「说的时间占比」）；
3. `共鸣分 = 50 + 25 × positionAvg`：位置 −1 → 25 分，0 → 50 分，+1 → 75 分。

### 3.3 各元音明细

卡片可展开「最近参考元音分布（估计）」：按时长列出每个最近邻参考元音、秒数与平均位置。它**不是音素识别**——每帧强制归到 12 个元音之一，没有「都不是」类别；过渡段、辅音、/ə/ 也会被贴标签。精确的元音 F1/F2 请用「长音测试」的自动判定。

---

## 四、综合分与分档

```text
综合分 = 0.55 × 音高分 + 0.45 × 共鸣分
```

没有共鸣分时：`综合分 = 音高分`。

| 分数 | 分档 |
| --- | --- |
| < 33 | 男性化参考 |
| 33–66 | 中性 / 过渡 |
| > 66 | 女性化参考 |

50 附近为中性；分档是连续分数上的三个区间，不是三个类别标签。

---

## 五、置信度

| 有效发声时长 | 置信度 |
| --- | --- |
| < 3 s | low |
| 3–10 s | medium |
| ≥ 10 s | high |

时长只代表样本量，不代表统计置信区间。短样本卡会提示「建议用 ≥10 秒朗读复核」。

---

## 六、局限

- 参考集是 1995 年的美式英语成人均值（男 n=45、女 n=48），不是普通话；元音标签只是最近邻近似；
- `position` 是「离哪套均值更近」的几何量，不是男性化 / 女性化百分比，也没有逐帧置信度；
- 男女参考云本身重叠，个体差异、方言、年龄、麦克风都会影响结果；
- 不包含语调、语速、气声、鼻化、发音习惯；VFP 原论文也指出 F0+VTL 基线对顺性别语料 R²≈0.94、对跨性别语料 R²≈0.53；
- 依赖 LPC 共振峰提取的准确度；环境噪声或气声会降低可靠性；
- 不是诊断，也不能替代人耳判断或临床评估。看趋势，不看单次绝对值。
