# 发版更新内容

每次发版前为 `package.json` 的 `version` 新增一个同名文件，例如 `0.10.2.json`。
构建时 `vite.config.ts` 会读取当前版本的文件，把 `notes` 通过
`__APP_VERSION_NOTES__` 注入前端；生产构建缺文件会直接失败。

格式：

```json
{
  "version": "0.10.2",
  "notes": {
    "zh-CN": "· 第一条\n· 第二条",
    "zh-TW": "· ...",
    "en": "· ...",
    "ja": "· ...",
    "es": "· ...",
    "fr": "· ...",
    "lzh": "· ..."
  }
}
```

- `version` 必须与 `package.json` 完全一致。
- `notes` 是纯文本，用 `\n` 换行；设置页会保留换行。
- 至少填写一个语言；缺某个语言时回退英文，再回退简体中文。
- 文件本身不会作为静态资源复制；当前版本的文案会通过 `define` 注入 JS 包。
- 更新内容卡仍只在「版本号发生变化」时显示，点「知道了」后关闭。
